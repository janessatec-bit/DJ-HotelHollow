# Como Executar o Projeto

## Requisitos
- Construct 3 instalado
- Navegador atualizado

## Passo a Passo

1. Baixe o repositório do GitHub.

2. Abra o Construct 3.

3. Clique em:
File → Open Project

4. Abra o arquivo:
     Hotel.c3p

5. Aguarde o carregamento do projeto.

6. Clique em Preview para executar o jogo.
