# Hotel Hollow

Hotel Hollow é um jogo de terror 2D top-down desenvolvido no Construct 3.

O jogador controla Lilith, uma funcionária presa em um hotel paranormal que precisa encontrar chaves espalhadas pelos quartos enquanto foge de uma entidade demoníaca.

---

# Sobre o Projeto

O projeto foi desenvolvido para a disciplina de Storytelling e Game Design, com foco em:
- exploração;
- suspense;
- perseguição;

A estética do jogo foi inspirada em animações estilizadas de terror, principalmente Hazbin Hotel.

---

# Gameplay

O jogador deve:
- explorar o hotel;
- coletar chaves;
- evitar o inimigo;
- desbloquear a saída;
- escapar do hotel.

---

# Mecânicas

- Movimentação WASD;

- IA de perseguição;
- Pathfinding;
- HUD dinâmico;
- Sistema de vitória e derrota.
